Privacy

Last updated: 1 November 2026

Kindi Headless is a personal, self-hosted assistant. Its operator controls the installation and the Google account connected to it. This public website contains information only.

Google data used by the assistant

After the account owner authorizes a connection, Kindi can access email messages and draft replies; calendar lists and events; Drive files, including Docs, Sheets and Slides; tasks; contact details; and Forms and their responses. These permissions support actions requested by the operator. Google’s authorization screen describes the permissions granted.

How data is processed

Kindi retrieves information needed for a request and processes it with the language model running on the operator’s computer. It can save requested changes to Google services. Gmail sends require a separate review and confirmation. Google account data is not used to train a general-purpose AI model, sold, or used for advertising.

Google data is used only to provide the personal assistance features the operator requests. Kindi follows the Google API Services User Data Policy, including its Limited Use requirements.

Storage and access

Authorization material is stored on the operator’s devices. Credentials are restricted to the integration service. During Windows setup, the refresh credential is protected with Windows user-bound encryption. The installed server uses operating-system access controls. The remote interface is restricted to the authorized private-network account.

Chat history can remain in the browser’s session storage. Draft records, action status and files deliberately saved by the operator can remain on the local installation. Draft email also remains in Gmail. Private records and credentials are not included in this public website.

External services

Google receives requests to its own services. If the operator enables public web search, search queries and requested URLs are sent to the relevant search providers or websites. Private Google content is not intended to be included in those public requests. This website adds no analytics, advertising, cookies, contact forms or third-party scripts. GitHub hosts the site and may process technical request information under its own privacy statement.

Control, retention and deletion

The account owner can revoke Kindi’s access from Google Account connections. Revocation stops subsequent authorized access; it does not automatically erase previously saved files or Gmail drafts. The operator can clear chat history, remove local integration credentials and records, and delete Google items through the relevant Google service. Local file versions remain until the operator removes them.

Questions

Contact the operator of your private Kindi installation for access, correction or deletion requests. The developer contact for the Google connection is identified in Google’s consent and connection settings.
